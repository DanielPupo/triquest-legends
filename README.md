# Trigonometry Quest

As razões (ou relações) trigonométricas estão relacionadas com os ângulos de um triângulo retângulo. As principais são: o seno, o cosseno e a tangente. 

São utilizadas para descrever as relações entre os diferentes lados de um triângulo retângulo. As principais incluem o seno, o cosseno e a tangente. 

Triângulo Retângulo: 

Um triângulo é classificado como retângulo quando possui um ângulo reto, ou seja, com 90º. 

Hipotenusa: 

Representa o maior lado do triângulo retângulo, e ele fica sempre localizado do lado oposto ao ângulo reto. 

Catetos: são os dois lados que formam o ângulo reto. Podem ser categorizados como cateto adjacente e cateto oposto. 

Para determinar se um lado é o cateto oposto ou adjacente em relação a um determinado ângulo em um triângulo retângulo, é necessário identificar o ângulo em questão. 

Ex: 

 

Cateto Oposto: É o lado que fica diretamente em frente ao ângulo de referência. 

Cateto Adjacente: É o lado vizinho que ajuda a formar esse mesmo ângulo, sem ser a hipotenusa. 

É importante destacar que o cateto oposto e o cateto adjacente podem trocar de papel, porque eles dependem exclusivamente de qual ângulo você está olhando,  

enquanto a hipotenusa nunca muda. 

Seno, cosseno e tangente: 

São as principais razões trigonométricas calculadas em um triângulo retângulo: 

Seno: É a divisão do cateto oposto pela hipotenusa; 

Cosseno: É a divisão do cateto adjacente pela hipotenusa;  

Tangente: É a divisão do cateto oposto pelo cateto adjacente. 

 

 

Para resolver problemas envolvendo as razões trigonométricas, devemos identificar qual é o ângulo de referência e qual das razões trigonométricas queremos usar. Outra informação importante para resolver esse tipo de problema são os ângulos notáveis, os ângulos notáveis são os ângulos de 30º, 45º e 60º, que são os mais comuns em questões de vestibulares e concursos. Para resolver exercícios envolvendo os ângulos notáveis, é necessário conhecer o valor do seno, do cosseno e da tangente para eles, o que pode ser conferido por meio de uma tabela trigonométrica. 

 

 

Identidades Trigonométricas 

São igualdades matemáticas válidas para qualquer valor de um ângulo onde as funções estão definidas. Elas servem para simplificar expressões, resolver equações e facilitar cálculos de integrais. 

Relação fundamental da trigonometria: 

Relaciona os valores do seno e do cosseno dado um mesmo ângulo, com base no teorema de Pitágoras. 

 

Passo a Passo de como resolver problemas envolvendo razões trigonométricas: 

Para encontrar lados desconhecidos de um triângulo retângulo, é necessário conhecer um ângulo e um de seus lados. 

1º passo: identificar qual razão trigonométrica deve ser usada. 

Para identificar qual razão utilizar, analisamos de qual lado conhecemos o valor e qual queremos descobrir em relação ao ângulo. Por exemplo, se a questão nos deu o valor da hipotenusa e quer que encontremos o valor do cateto adjacente, a razão que relaciona cateto adjacente e hipotenusa é o cosseno. Utilizamos esse mesmo raciocínio para identificar se é o seno ou a tangente. 

2º passo: aplicar a fórmula da razão trigonométrica que identificamos no passo anterior com os valores dos lados do triângulo. 

3º passo: consultar na tabela o valor da razão trigonométrica escolhida para o ângulo de referência 

e substituir na fórmula. 

4º passo: resolver a equação e encontrar o valor desejado. 

 

Nome do jogo: Triquest  

Público-alvo: O jogo será destinado para alunos do ensino médio da escola SESI 

Objetivo do jogo: O objetivo do jogo é a revisão dos conteúdos sobre Razões trigonométricas de maneira divertida. 

Regras: 

Entrada no Jogo 

Ao iniciar o jogo, o jogador poderá: 

Inserir seu nome;  

Acessar os diferentes temas de estudo;  

Consultar as instruções do jogo;  

Acessar seu perfil e seu desempenho.  

Os temas disponíveis incluem: 

Seno;  

Cosseno;  

Tangente;  

Razões no Triângulo.  

 

Início dos Desafios 

Ao selecionar um tema ou iniciar uma rodada, o jogador começa uma sequência de 10 desafios matemáticos. 

Cada desafio apresenta uma situação envolvendo conceitos de trigonometria. Os problemas podem envolver, por exemplo: 

Cálculo de alturas;  

Cálculo de distâncias;  

Comprimento de rampas;  

Medidas de lados de triângulos;  

Identificação de lados do triângulo;  

Aplicação de Seno, Cosseno e Tangente;  

Situações-problema do cotidiano.  

 

Análise do Problema 

Antes de responder, o jogador deve observar o triângulo e analisar as informações fornecidas. 

É necessário identificar: 

Hipotenusa;  

Cateto Oposto;  

Cateto Adjacente;  

Ângulo de referência;  

Medida que precisa ser encontrada.  

A partir dessas informações, o jogador deverá escolher a estratégia matemática adequada para solucionar o desafio. 

 

Escolha da Razão Trigonométrica 

O jogador deverá selecionar a razão trigonométrica adequada ao problema. 

Seno 

Cateto Oposto / Hipotenusa 

Cosseno 

Cateto Adjacente / Hipotenusa 

Tangente 

Cateto Oposto / Cateto Adjacente 

Depois de realizar o cálculo, o jogador deverá selecionar a alternativa correta e confirmar sua resposta. 

 

Sistema de Dicas 

Durante os desafios, o jogador poderá utilizar a opção Dica. 

A dica tem como objetivo auxiliar na resolução do problema sem entregar diretamente a resposta. 

O recurso pode apresentar informações como: 

Qual razão trigonométrica pode ser utilizada;  

Identificação dos lados do triângulo;  

Valores de ângulos notáveis;  

Orientações para realizar o cálculo.  

Quando o jogador utiliza uma dica e acerta a questão, recebe uma pontuação menor do que receberia acertando sem auxílio. 

 

Sistema de Pontuação 

A pontuação é baseada no desempenho do jogador em cada desafio. 

Acerto de Primeira 

100 Pontos  

O jogador responde corretamente sem utilizar a dica e recebe a pontuação máxima do desafio. 

Acerto com Dica 

50 Pontos 

Caso o jogador utilize a Dica e responda corretamente, recebe 50 pontos. 

Resposta Incorreta 

Quando o jogador erra, não perde pontos. 

O jogo apresenta um Feedback, explicando o erro e mostrando informações que ajudam o jogador a compreender a resolução do problema. 

 

Sistema de Vidas 

Cada rodada possui 3 vidas. 

As vidas são utilizadas durante os desafios e ficam indicadas na tela do jogo. 

Caso o jogador perca todas as 3 vidas, a rodada é encerrada e será apresentada a tela de derrota, mostrando a pontuação alcançada. 

O jogador poderá escolher entre: 

Tentar novamente;  

Voltar ao início.  

 

Rodadas 

O TriQuest não possui fases ou mundos. 

O jogo funciona por meio de rodadas de 10 desafios. 

Primeira Rodada 

O jogador recebe 10 desafios selecionados pelo sistema e deve avançar por eles até concluir a rodada ou perder todas as suas vidas. 

Nova Rodada 

Ao concluir os 10 desafios, uma nova rodada é iniciada. 

Os desafios são aleatorizados, fazendo com que o jogador receba um novo conjunto de 10 questões. 

Dessa forma, cada rodada pode apresentar uma combinação diferente de problemas, tornando a experiência mais dinâmica e permitindo que o jogador pratique os conteúdos várias vezes. 

 

Como Concluir uma Rodada 

Cada rodada possui 10 desafios. 

Ao chegar ao décimo desafio, o jogo calcula o desempenho do jogador e apresenta sua pontuação final. 

A pontuação é determinada pela quantidade de acertos, pelo uso ou não de dicas e pelos bônus de rapidez conquistados durante a rodada. 

Após o término, o jogador pode iniciar uma nova rodada com 10 novos desafios aleatorizados. 

 

Resultado 

Ao terminar uma rodada, o jogador recebe uma tela de resultado. 

Caso tenha alcançado a pontuação necessária (no mínimo 700 pontos) 

Será apresentada uma mensagem de vitória, juntamente com: 

Pontuação final;  

Reconhecimento pelo desempenho;  

Animação de comemoração;  

Opção de jogar novamente;  

Opção de voltar ao início.  

Caso a pontuação não seja suficiente (menos do que 700 pontos) 

Será apresentada uma mensagem de encerramento, juntamente com: 

Pontuação final;  

Feedback sobre o desempenho;  

Incentivo para continuar praticando;  

Opção de tentar novamente;  

Opção de voltar ao início.

---

### 1. Visão Geral do Projeto

- **Nome do Jogo:** TriQuest

- **Objetivo Educacional:** Ensinar e fixar conceitos de razões trigonométricas no triângulo retângulo (Seno, Cosseno e Tangente) para estudantes do Ensino Médio.

- **Tecnologias:** HTML5, CSS3 puro (design responsivo mobile-first), JavaScript ES6+ (Módulos) e Firebase Firestore (Backend para Ranking).

- **Estilo Visual:** Interface moderna, tema escuro/dark mode, cartões bem definidos, botões interativos e suporte a SVGs vetoriais dinâmicos.

---

### 2. Regras de Negócio e Mecânicas

1. **Mundos/Fases:** O jogo possui 10 perguntas divididas em 3 Mundos:

   - *Mundo 1: Vale dos Identificadores* (Identificação de Hipotenusa, Catetos Oposto e Adjacente).

   - *Mundo 2: Templo dos Ângulos Notáveis* (Cálculos com 30°, 45° e 60°).

   - *Mundo 3: Montanha das Aplicações Reais* (Problemas práticos de altura, rampas e sombras).

2. **Sistema de Vidas:** O jogador inicia com 3 vidas. Cada erro remove 1 vida. Se chegar a 0, vai para a tela `sem-vidas.html`.

3. **Pontuação:**

   - Acerto de primeira: +100 pontos.

   - Bônus de tempo (<45 segundos): +20 pontos.

   - Uso de Dica/Oráculo: limita os pontos da questão a +50.

4. **Condição de Vitória:** É necessário acertar no mínimo 7 das 10 questões para vencer (`vencedor.html`). Caso contrário, o jogador vai para `perdedor.html`.

---

### 3. Integração com Backend (Firebase Firestore)

O arquivo de estado (`state.js`) deve utilizar a SDK do Firebase Firestore v10 para:

- Registrar cada tentativa finalizada na coleção `ranking` com os campos: `playerName` (string), `score` (number), `totalCorrect` (number) e `createdAt` (timestamp).

- Disponibilizar a função `getTopRanking()` para ler os 10 melhores resultados ordenados por pontuação descendente.

---

### 4. Arquivos do Projeto a serem Gerados/Ajustados

Gere o código completo, limpo e funcional para a seguinte estrutura:

1. `state.js`: Módulo de gerenciamento de estado local (`localStorage`) integrado às chamadas do Firebase Firestore.

2. `questions.js`: Banco de dados de 10 questões com geradores de figuras triangulares dinâmicas em SVG (funções `buildTriangleFigure`, `buildLadderFigure`, etc.).

3. Páginas HTML interativas:

   - `index.html`: Tela de boas-vindas e entrada.

   - `cadastro.html`: Input do nome do jogador.

   - `home.html`: Dashboard com saudações, seleção de mundos e botão de início.

   - `pergunta.html`: Interface principal do jogo com renderização de questão, timer, sistema de vidas, botões de opção, dica (modal do Oráculo Trigonométrico com tabela de ângulos) e envio da resposta.

   - `acerto.html` / `erro.html`: Feedback imediato da resposta.

   - `vencedor.html` / `perdedor.html` / `sem-vidas.html`: Telas de encerramento enviando a pontuação para o Firebase.

   - `regras.html`: Instruções e tabela de medalhas.
